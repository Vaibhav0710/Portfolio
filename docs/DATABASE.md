# Database

None. The site has no database: all content is static data in `src/lib/constants.ts`, built into the page at
build time. Contact form messages go to Web3Forms and arrive by email; nothing is stored by this project.

Planned: per-application tracked links and visit analytics (Job/PLAN.md section 9) may need storage. If added, it
will be documented here (engine, schema, migrations, connection env vars).
